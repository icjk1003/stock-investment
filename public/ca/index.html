How are dividends applied?

We apply per-share dividends on payout dates. If DRIP is on, dividends buy more shares.

Do I need FX for Canada?

If you model CAD cashflows buying USD ETFs, FX matters (CADUSD). Region settings can reflect that.

Is QQQ still meaningful with low yield?

Yes. Backtesting recurring buys + price returns is still useful for comparison and planning.
